# clickhouse_loader

Пошаговый загрузчик файлов в ClickHouse: CSV / TSV / TXT (в т.ч. `.gz`), Excel (`.xlsx`, `.xlsm`), Parquet.
Один файл — `ch_loader.py`; задаёт вопросы по шагам, ничего не перезаписывает без подтверждения.

## Установка и запуск

```bash
pip install -r requirements.txt
python ch_loader.py
```

Что подготовить: адрес сервера (хост, `хост:порт` или URL — порт и протокол определяются сами),
логин/пароль, базу, путь к файлу, имя таблицы. Для новой таблицы — колонки для `ORDER BY`
(по которым чаще фильтруете; после создания не меняется).

## Как обеспечивается корректность

| Шаг | Что происходит |
|-----|----------------|
| Подключение | Перебор HTTP 8123 / HTTPS 8443 / TCP 9000 / TCP+TLS 9440, отличает «не тот протокол» от «неверный пароль» |
| Кодировка | UTF-8 проверяется по всему файлу; иначе — угадывается (cp1251, koi8-r, cp866…) и показывается пример |
| Разбор CSV | Быстрый путь (pyarrow) только после строгой проверки RFC 4180; при сомнении — строгий построчный разбор и исправление «кривых» кавычек с подтверждением |
| «Вечные кавычки» | `"ООО ""Ромашка"""` → `ООО "Ромашка"` — с примерами и вопросом |
| Типы | По **всему** файлу, без потерь: ведущие нули → String, `12,5` → Decimal, `31.12.2024` → Date, несуществующие даты → String |
| Загрузка | Временная таблица → сверка числа строк → `RENAME` (новая) или один `INSERT … SELECT` (существующая) |
| Конфликты | Переполнение, округление, лишние/недостающие колонки, NULL в не-Nullable, возможные дубликаты — вопрос пользователю |
| Замена | Только после ввода имени таблицы; старые данные остаются в `<таблица>__backup_<время>` |
| Сбой сети | Повтор пачки с тем же `insert_deduplication_token` — без дублей |

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q tests                                  # модульные, сервер не нужен
CH_TEST_HOST=localhost pytest -q tests           # + интеграционные (HTTP 8123 и TCP 9000)
```

- `tests/test_types.py` — выбор типов, совместимость с таблицей, строгая конвертация.
- `tests/test_parsing.py` — кодировки, разделители, заголовок, кавычки, битые строки, Excel, Parquet, адрес сервера.
- `tests/test_integration.py` — загрузка в настоящий ClickHouse по обоим протоколам, повтор без дублей,
  остановка до записи при недопустимом значении.

## Ограничения

- Время со смещением `+03:00` хранится текстом (с `Z` — как UTC); разделители тысяч пробелами не распознаются.
- Числа из Excel округляются до 15 значащих цифр (точность самого Excel).
- Новая таблица создаётся как `MergeTree` без `ON CLUSTER`.
- По TCP доли секунды точнее микросекунд не передаются — используйте HTTP.
