# Правила для Claude в этом репозитории

## Тесты с ClickHouse
- Тесты с ClickHouse запускаются ТОЛЬКО на локальном демо-сервере в Docker на ПК пользователя.
  Команду и машину для этого пользователь даёт отдельно.
- НЕ скачивать и НЕ запускать ClickHouse внутри облачного контейнера сессии.
- Без такого сервера запускать только модульные тесты (`pytest -q tests` в clickhouse_loader —
  интеграционные пропускаются сами) и явно сообщать, что интеграционные не запускались.
