# Отчёт из сводной таблицы — макрос Excel (V3)

Файл для импорта: `dist/modОтчетИзСводнойV3.bas` (Windows-1251, CRLF).
Редактировать — `src/modОтчетИзСводнойV3.bas` (UTF-8), затем `python3 build.py`.

## Макросы

| Макрос | Что делает |
|---|---|
| `ОформитьОтчёт` | встать в сводную и запустить — строит отчёт на новом листе или в новой книге |
| `ОформитьОтчётБезВопросов` | то же без диалогов (для вызова из других макросов) |
| `ПалитраОтчёта` | сменить палитру готового отчёта на активном листе (спросит номер) |
| `ПалитраСледующая` | переключить палитру по кругу |
| `ПалитраНомер n` | применить палитру n (удобно для кнопок на панели быстрого доступа) |

После построения на листе нет ничего, кроме отчёта: палитра определяется
по самим заливкам, служебных ячеек и панелей нет.

## Тесты ядра

Разбор структуры строк и шапки отделён от Excel (`'#ЯДРО-НАЧАЛО … '#ЯДРО-КОНЕЦ`)
и прогоняется в LibreOffice Basic (режим VBASupport) на сгенерированных сводных:

```
cd tests && python3 test_core.py      # все 1560 кейсов
python3 test_core.py 100              # случайная выборка
python3 perf.py                       # время ядра на 6 и 21 тыс. строк
```

Перебираются: глубина 1–10; макет сжатый / структурный / табличный;
итоги сверху / снизу / без них; повтор подписей; общий итог; пустые строки
после групп; тёзки у разных родителей, подписи-числа и «итоговые» слова
в названиях; три режима того, что сообщает Excel (поле каждой ячейки,
только тип линии оси, ничего — только текст и отступ).

Excel-обвязка (снятие данных со сводной, вывод, перекраска) в тестах
не исполняется — её проверка только в Excel.
